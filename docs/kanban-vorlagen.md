# Kanban-Vorlagen

Diese Karten bekommt **jedes Flugzeug** zu Saisonbeginn (Vorlagen ohne Flugzeugtyp). Übernommen aus der
Winterwartungs-Checkliste des Vereins; jede Zeile der Liste ist eine Karte, pro Bauteil eine eigene.
Zum Bearbeiten vor dem Import in die echte Datenbank.

**Stufe und Dauer stehen nicht in der Checkliste** – die Werte hier sind Vorschläge, bitte anpassen.

Format pro Karte (bitte beibehalten, der Import liest die Datei):

- `## Titel` – Überschrift der Karte, Bauteil vorne (z. B. „Rumpf: Reinigen“)
- `Stufe:` Einsteiger · Erfahren · Werkstattleiter
- `Dauer:` Freitext, z. B. „~2 h“
- `Dokument:` Titel des verlinkten Dokuments (optional, weglassen wenn keins)
- danach die Beschreibung als Absatz (optional)
- danach die Checkliste als `- [ ]`-Zeilen (optional; leer = die Karte hat keine Checkliste)

Karten löschen = Abschnitt löschen, neue Karten = neuer `##`-Abschnitt. Die Reihenfolge in der Datei ist die
Reihenfolge auf dem Board. Nur für einen Flugzeugtyp gedacht? Dann `Typ: ASG32` als Zeile ergänzen.
